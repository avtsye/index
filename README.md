# דף הפרויקטים של avtsye

המאגר הזה הוא מקור הקוד הראשי לדף הבית הציבורי: https://avtsye.github.io/index/.
הפרויקטים, התיאורים, השפות, הנושאים והפעילות נטענים מהפרופיל הציבורי ב־GitHub. נושא `featured` מבליט פרויקט, ונושא `hide-homepage` מסתיר אותו מהדף. כתובת אתר בדף מאגר ב־GitHub משמשת ככפתור "פתיחת האתר".

טופס יצירת הקשר שולח הודעות לשרת נפרד ב־Render, ששומר אותן כ־Issues במאגר פרטי. אין לשמור מפתחות או טוקנים בקוד האתר. בדיקת זמינות אוטומטית נמצאת ב־`.github/workflows/contact-health.yml`.

לבדיקה מקומית: `node scripts/check-site.mjs` ואז להגיש את התיקייה באמצעות שרת קבצים סטטי. GitHub Pages מפרסם את ענף `main` כמקור הציבורי. גרסת Sites, אם קיימת, משמשת עותק לבדיקה ואינה מקור הפרסום הראשי.

דומיין אישי עדיין לא הוגדר; להגדרתו נדרש דומיין שבבעלות בעל האתר ורשומות DNS מתאימות.
